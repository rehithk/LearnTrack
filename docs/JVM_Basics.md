# JVM Basics

**JVM** runs the program. **JRE** is JVM + standard libraries. **JDK** is JRE + compiler. Since I'm writing code I installed JDK.

**Bytecode** is what javac produces when you compile a .java file. It's not machine code, it's a middle layer that the JVM reads and executes.

**Write once run anywhere** means the same .class file runs on any OS that has a JVM. You don't recompile for each platform, the JVM handles it.
